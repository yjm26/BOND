## Variant: Who + Lifecycle (stark mono)

### Design stance
Decide/Learn surface — teach *who* and *path* without SaaS feature grids. BOND DESIGN.md mono + Emil: quiet, concrete, press feedback, ease-out only on occasional section/hover.

### Key choices
- Layout: editorial rows for audience; 5-column lifecycle rail on dark band
- Typography: Inter medium headlines + JetBrains Mono labels
- Color: paper/ink only; success/danger soft only on ending labels
- Interaction: lifecycle hover updates “next action” copy (one state transition)

### Trade-offs
- Strong at: product clarity, trust honesty, on-brand with live app
- Weak at: no live hero room component fidelity (simplified shell)

### Best for
- Landing extension before shipping into `frontend/src/components/landing/`
